# customer_behavior_report
Data analysis Learning process
Customer Shopping Behaviour Analysis

A complete end-to-end data analytics project that analyzes customer shopping behaviour using Python, SQL, and Power BI. The project covers the complete analytics workflow — from data loading and cleaning to exploratory analysis, SQL-based business analysis, dashboard creation, and final reporting.

📌 Overview

This project focuses on understanding customer purchasing patterns, spending behaviour, subscriptions, product preferences, and other key business insights.

The analysis was performed using Python for data exploration and cleaning, SQL for business queries, and Power BI for interactive visualization. A professional report and presentation were also created to communicate the findings clearly.

🎯 Project Objectives
Understand customer shopping behaviour
Clean and prepare the dataset for analysis
Perform Exploratory Data Analysis (EDA)
Identify important customer and purchasing trends
Answer business questions using SQL
Build an interactive Power BI dashboard
Generate actionable business insights
Present the analysis through a professional report and PPT
